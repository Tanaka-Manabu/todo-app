# 画面遷移図

**バージョン:** 1.0  
**作成日:** 2026-05-05

---

## 1. 全体遷移図

```
[未認証ルート]                      [認証済みルート]
─────────────                      ─────────────────
/                                  /dashboard
/login          ─── ログイン成功 ──▶  /tasks
/register                          /tasks/[id]
/verify-email                      /tasks/[id]/edit
/password/reset                    /categories
                                   /profile
                                   /settings
```

---

## 2. 認証フロー

```
┌─────────────┐
│  / (トップ)  │
└──────┬──────┘
       │
       ├─── 未ログイン ──▶ ┌──────────────┐
       │                  │  /login       │
       │                  │  ログイン画面  │
       │                  └──────┬───────┘
       │                         │
       │                  ┌──────┴───────────────────────────┐
       │                  │                                  │
       │              ログイン成功                    「新規登録」クリック
       │                  │                                  │
       │                  ▼                       ┌──────────────────┐
       │           /dashboard                     │  /register        │
       │                                          │  ユーザー登録画面 │
       │                                          └──────┬───────────┘
       │                                                 │
       │                                          登録成功（確認メール送信）
       │                                                 │
       │                                          ┌──────▼───────────┐
       │                                          │  /verify-email    │
       │                                          │  メール認証画面   │
       │                                          └──────┬───────────┘
       │                                                 │
       │                                          メール認証完了
       │                                                 │
       └─── 認証済み ────────────────────────────▶ /dashboard
```

**パスワードリセットフロー:**
```
/login
  └─「パスワードを忘れた」クリック
       ▼
  /password/reset（メール入力）
       │
  メール送信 → ユーザーがリンクをクリック
       ▼
  /password/reset?token=xxx（新パスワード入力）
       │
  リセット完了
       ▼
  /login
```

## 3. メイン画面遷移

```
/dashboard（ダッシュボード）
  │
  ├── サイドバー「タスク」クリック
  │       ▼
  │   /tasks（タスク一覧）
  │       │
  │       ├── タスク行クリック ──▶ /tasks/[id]（タスク詳細）
  │       │                             │
  │       │                         「編集」クリック ──▶ /tasks/[id]/edit（タスク編集）
  │       │                             │                       │
  │       │                             │                   更新完了 ──▶ /tasks/[id]
  │       │                             │
  │       │                         「削除」クリック ──▶ 確認ダイアログ ──▶ /tasks（一覧に戻る）
  │       │
  │       ├── 「+タスク追加」クリック ──▶ タスク作成モーダル（一覧画面上に重ねて表示）
  │       │                                  │
  │       │                              作成完了 ──▶ 一覧にインサート（ページ遷移なし）
  │       │
  │       └── フィルタ・検索操作 ──▶ URLクエリパラメータ更新（ページ遷移なし）
  │
  ├── サイドバー「カテゴリ」クリック
  │       ▼
  │   /categories（カテゴリ管理）
  │       │
  │       ├── 「+追加」クリック ──▶ 作成モーダル
  │       └── カテゴリ行「編集」クリック ──▶ 編集モーダル
  │
  ├── ヘッダー「通知アイコン」クリック ──▶ 通知パネル（ドロップダウン）
  │
  └── ヘッダー「プロフィールアイコン」クリック
          │
          ├── 「プロフィール設定」 ──▶ /profile
          └── 「ログアウト」 ──▶ /login
```

## 4. 画面一覧

### 4.1 未認証画面

| 画面名 | パス | 説明 |
|--------|------|------|
| ログイン | `/login` | メール・パスワード入力、「パスワードを忘れた」リンク |
| 新規登録 | `/register` | 表示名・メール・パスワード入力 |
| メール認証 | `/verify-email` | 認証メールの確認待ち案内 |
| パスワードリセット要求 | `/password/reset` | リセットメール送信フォーム |
| パスワード再設定 | `/password/reset?token=xxx` | 新パスワード入力フォーム |

### 4.2 認証済み画面

| 画面名 | パス | 説明 |
|--------|------|------|
| ダッシュボード | `/dashboard` | 今日のタスク・期限切れ・完了率のサマリー |
| タスク一覧 | `/tasks` | フィルタ・検索・ソート対応のタスク一覧 |
| タスク詳細 | `/tasks/[id]` | タスク全情報・サブタスク一覧・タグ |
| タスク編集 | `/tasks/[id]/edit` | 各フィールドの編集フォーム |
| カテゴリ管理 | `/categories` | カテゴリの一覧・追加・編集・削除 |
| プロフィール | `/profile` | 表示名・アバター・パスワード変更 |

## 5. 主要コンポーネントとモーダル

| コンポーネント名 | 表示箇所 | 説明 |
|----------------|---------|------|
| タスク作成モーダル | `/tasks` 上 | タイトル・優先度・期限・カテゴリを入力して即時作成 |
| タスク削除確認ダイアログ | タスク詳細・一覧 | 「本当に削除しますか？」確認 |
| カテゴリ作成/編集モーダル | `/categories` 上 | 名前・カラーを入力 |
| タグ付与パネル | タスク詳細・編集 | タグのインライン追加・削除 |
| 通知パネル | ヘッダー | 期限リマインダー等の一覧・既読操作 |
| トースト通知 | 全画面 | 操作の成功・失敗を画面右下に一時表示 |

---

## 6. URL設計方針

- リソースベースのRESTful URLを採用（`/tasks/[id]`）
- フィルタ・検索・ソート条件はクエリパラメータで管理し、ブックマーク・シェア可能にする
  - 例: `/tasks?status=todo&priority=high&sort=due_date&order=asc`
- モーダルや一時的なUIはURLを変えない（`?modal=create` のような形は使わない）
- 認証済みルートへの未認証アクセスは `/login?redirect=/tasks` にリダイレクト
